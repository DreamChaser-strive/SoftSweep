# SoftSweep 净软

SoftSweep 是一款仅在本机运行的 Windows 软件卸载与残留清理工具。它会汇总传统桌面程序、Microsoft Store 应用、系统组件和驱动程序，并在用户逐项确认后清理关联的安装目录、用户数据、公共数据、快捷方式和注册表项。

项目不会上传软件列表、文件路径、注册表内容或清理结果。服务只监听 `127.0.0.1`，并使用随机端口与一次性访问令牌。

![SoftSweep 应用图标](assets/app.png)

## 主要功能

- 扫描 HKLM、HKCU 卸载注册表以及 Microsoft Store 应用。
- 按开发工具、办公、浏览器、影音、实用工具、系统组件、驱动和运行库等类别展示。
- 统计每款软件实际占用空间，Microsoft Store 应用同时统计安装目录与 `%LOCALAPPDATA%\Packages` 应用数据。
- 优先调用软件自己的官方卸载程序，再重新扫描卸载后的残留。
- 识别安装目录、`AppData`、`ProgramData`、开始菜单、桌面快捷方式和常见注册表项。
- 清理前展示完整路径、大小、置信度和风险，必须由用户确认。
- 默认移入回收站；永久删除必须输入完整软件名称，确认时自动兼容全角/半角括号、多余空格和不可见字符。
- 删除注册表项前自动导出 `.reg` 备份。
- 阻止清理系统根目录、用户目录根、文档、下载、图片、视频、音乐等个人资料目录。
- 支持任务中断后的待确认清理记录恢复，并生成 UTF-8 清理报告。
- 独立 `SoftSweep.exe` 以无地址栏的应用窗口运行，不要求安装 Python。

## 下载并运行

1. 打开仓库右侧的 **Releases**。
2. 下载最新版本中的 `SoftSweep-win-x64.zip`。
3. 解压到任意目录，不要只从压缩预览中直接运行。
4. 双击 `SoftSweep.exe`。
5. Windows 如果显示 SmartScreen，请选择“仍要运行”。首次扫描系统软件可能需要几分钟。

建议以管理员身份运行，以便扫描和清理 `HKLM`、`Program Files` 等系统位置。普通权限仍可运行，但部分系统级项目无法删除。

## 安全设计

SoftSweep 的目标不是“尽可能删掉更多东西”，而是避免破坏 Windows 和正在使用的软件：

- 官方卸载程序优先，只有卸载注册项消失后才进入残留清理阶段。
- 受保护的系统组件、驱动、运行库和关键 Windows 目录不会提供自动卸载。
- 宽泛名称匹配的项目会显示为谨慎或高风险，并可取消勾选。
- 文件默认进入回收站，注册表删除前会先生成 `.reg` 备份。
- 永久删除需要手动输入完整软件名称；全角/半角、多余空格和不可见字符不会导致误判。
- 个人资料目录只读展示，不作为自动清理候选项。
- 清理前始终显示逐项路径；不确定的项目建议先移入回收站。

## 从源码运行

环境要求：

- Windows 10 或 Windows 11
- Python 3.10 或更高版本
- Microsoft Edge 或 Google Chrome（用于应用式窗口）

执行：

```powershell
python .\app.py
```

也可以双击：

```powershell
.\启动.bat
```

启动器会自动寻找可用的 `pythonw.exe`，并在普通权限下尝试申请管理员权限。

## 构建独立 EXE

安装构建依赖：

```powershell
python -m pip install pyinstaller pillow
```

构建并生成 ZIP：

```powershell
python build.py
```

输出：

```text
dist\SoftSweep.exe
release\SoftSweep-win-x64.zip
```

## 常见问题

### 为什么有些软件没有图标？

部分控制台工具、旧版安装器或已删除安装目录的软件本身没有可提取图标。SoftSweep 会显示软件名首字母作为回退，不会猜测或借用其他软件图标。

### 清理后可以恢复吗？

使用“移入回收站”时，文件和目录可以像普通删除一样从回收站恢复。注册表项会导出到：

```text
%LOCALAPPDATA%\SoftSweep\backups
```

永久删除没有软件内置恢复能力，请谨慎使用。

### 为什么扫描需要管理员权限？

普通权限可以读取大部分卸载信息，但无法可靠访问或清理所有 `HKLM`、`Program Files` 和公共数据位置。管理员模式可让扫描和清理结果更完整。
